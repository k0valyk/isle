# Android-компаньйон Isle

Окремий Android-застосунок (Kotlin, без сторонніх бібліотек), який:
- приймає сповіщення з телефона і надсилає їх на ПК в острів Isle;
- передає файли з телефона в `Завантаження\Isle Phone` на ПК;
- пейриться 6-значним кодом, який показує острів у вкладці «Телефон».

## Збірка

Потрібен Android Studio (або Android SDK + Gradle 8.2+).

```powershell
# Варіант 1: відкрий папку android-companion в Android Studio і натисни Run.
# Варіант 2: якщо встановлено gradle:
cd android-companion
gradle wrapper
.\gradlew.bat assembleDebug
```

APK: `android-companion\app\build\outputs\apk\debug\app-debug.apk`.

## Підключення

1. На ПК відкрий Isle → вкладка «Телефон». Там видно адресу `IP:45872` і 6-значний код.
2. Телефон і ПК мають бути в одній Wi-Fi мережі.
3. У застосунку введи адресу та код, натисни «Pair».
4. Дай дозвіл «Доступ до сповіщень» (Android Settings → Notification access).
5. Готово: нові сповіщення з'являються в Isle і як системні тости Windows.

## Безпека

- Сервер Isle слухає лише локальну мережу на порту 45872.
- Без правильного коду пейринг неможливий; після пейрингу всі запити потребують токен.
- Дані не проходять через інтернет. Вимкни Windows Firewall для приватної мережі, якщо
  телефон не бачить ПК (або дозволь Java/Isle у приватній мережі).

## Обмеження

- Відповіді на сповіщення з ПК (RemoteInput) не реалізовано: Android дозволяє їх лише
  через власний застосунок-відправник.
- Файли передаються в один бік (телефон → ПК). Зворотний напрямок — через теку
  `Isle Phone`, яку можна відкрити в провіднику.
- iPhone: системні сповіщення iOS не можна пересилати стороннім застосункам. На iPhone
  доступна веб-версія Isle (`http://IP:45872`) для буфера обміну та файлів.
