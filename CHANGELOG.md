# Changelog

## 1.7.0 — 2026-11-18

### Оновлення
- Оновлення всередині застосунку: Isle сам перевіряє GitHub Releases, завантажує підписаний інсталятор і перезапускається. Кнопка «Перевірити оновлення» — у Налаштуваннях → Про застосунок.
- Одноразовий дозвіл для FPS та системних датчиків: замість запиту прав адміністратора щоразу Isle один раз створює підвищену задачу планувальника й далі запускається через неї без UAC.
- Автозапуск узгоджено з підвищеною задачею: подвійного запуску більше немає.

## 1.6.1 — 2026-11-17


### Дизайн
- Нова палітра: теплий графіт замість синьо-фіолетового скла; один акцент, що використовується рідко.
- Три рівні поверхонь і волосяні рамки; прибрано кольорові тіні, градієнтні картки, свічення та неонові рамки.
- Типографіка: шкала 10.5/12/13/15/18, ваги 400–600, табличні цифри, sentence case без трекінгу.
- Налаштування: сайдбар 232 px, рядки 44 px, спокійніший ритм, читабельність у світлій і темній темах.
- Плеєр: обкладинка як головний акцент, більше повітря, без свічення тексту пісні; висота 404 px проти обрізання.
- Острів: волосяна світла лінія по верхньому краю, нейтральна глибина.
- Поважає `prefers-reduced-motion` і `prefers-reduced-transparency`.
- Дизайн-система задокументована в `docs/DESIGN.md`.

### Функції
- Заставки острова: зорі, полярне сяйво, бульбашки, матриця, HUD навантаження, власна GIF.
- FPS-монітор, сторінка використання агентів, оновлена панель агентів.
- Регулятор системної гучності в плеєрі (коректно знімає mute при піднятті рівня).
- Закріплення острова, персонажі «кіт» і «сфера», гарячі клавіші play/pause, next, prev.

### Виправлено
- Позиція острова більше не губиться після скріншота.
- «Скинути позицію» повертає острів на головний екран.
- Малювання в редакторі не тягне вікно.
- Прибрано горизонтальне переповнення у плеєрі.
- Дрібні підписи більше не губляться через `text-transform` і замалий кегль.

### macOS
- Перша публічна universal-збірка (Apple Silicon + Intel): острів, таймер зі звуком, переклад, нотатки, буфер, погода, чат, налаштування, скріншоти через `screencapture`, статистика, батарея, автозапуск, термінал.
- Ще немає: музики/обкладинок (MediaRemote), FFT-візуалізації, OCR, GPU/температур, глобальних хоткеїв.

## 1.6.0 — 2026-11-15

- Візуалізації музики (9 стилів), анімації тексту пісні (4), профілі анімацій острова (4).
