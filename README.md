# Isle — живий острів для Windows

Dynamic Island для Windows 10/11: капсулоподібний острів, який розкривається
наведенням або гарячою клавішею і працює як маленький центр керування ПК.

**Безкоштовно. Локально. Без телеметрії та обов'язкових акаунтів.** MIT.

## Технології

- **Tauri 2** (Rust) + WebView2, **Svelte 5** + TypeScript + Vite
- **SQLite** (rusqlite) для буфера, нотаток, календаря, нагадувань і чату
- Frontend-анімації: Svelte 5 + `motion` (spring-числа), `gsap` (sheen при розкритті), `animate.css` (акцентні ефекти), `lottie-web` (дзвіночок таймера, ліниво)
- Нативні Win32/WinRT: `SetWindowRgn`, SMTC, Windows.Media.Ocr, GDI-скріншоти, ConPTY
- Локальні HTTP-сервери на `127.0.0.1` для хуків агентів і на LAN для телефона

## Збірка

```powershell
# 1. Rust: https://rustup.rs/
# 2. Node.js LTS: https://nodejs.org/
# 3. WebView2 Runtime: https://developer.microsoft.com/microsoft-edge/webview2/
cd D:\island
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force
.\build.ps1 -Release
```

Release-бінар: `src-tauri\target\release\isle.exe`.

Важливо: release потрібно збирати через Tauri CLI або з фічею `custom-protocol`
(інакше бінар шукатиме dev-сервер):

```powershell
npx.cmd tauri build --no-bundle
# або
cd src-tauri; cargo build --release --features custom-protocol
```

Розробка: `npm.cmd run dev` + `npx.cmd tauri dev`.

## Гарячі клавіші та керування

- `Alt+Space` — розгорнути/згорнути острів (якщо зайнято — `Alt+Shift+Space`, далі `Ctrl+Alt+Space`)
- `Esc` — згорнути
- Перетягни острів за верхню смугу або затисни `Ctrl` і тягни будь-яке місце — позиція зберігається
- Біля краю екрана острів прикріплюється (top/left/right/bottom); панель розкривається вбік від краю
- `Alt+←/→/↑/↓` — точне переміщення (зі `Shift` — швидше); після цього острів стає вільним
- Клік / подвійний клік по острову — розгорнути (залежно від режиму в налаштуваннях)
- Ліва кнопка на треї — перемкнути острів; меню — налаштування/згорнути/вихід

## Телефон

1. Відкрий Isle → «Телефон», побачиш `IP:45872`, 6-значний код і QR.
2. **Android:** збери `android-companion` в Android Studio (інструкція в `android-companion/README.md`),
   введи адресу та код, дай доступ до сповіщень.
3. **iPhone:** відкрий `http://IP:45872` у Safari (або наведи камеру на QR), введи код,
   додай сторінку на Домашній екран. Працюють буфер обміну у два боки та передача файлів.
4. Сповіщення Android з'являються в острові й як тости Windows; файли — у `Завантаження\Isle Phone`.

## Агенти

```powershell
cd hooks\isle-hook
cargo build --release
isle-hook claude stop "Завдання виконано"
```

Endpoint: `http://127.0.0.1:45871/event`. Приклади конфігурації — `hooks/isle-hook/README.md`.

**OpenCode:** у Isle → «Агенти» натисни «Встановити» — плагін з'явиться в
`%USERPROFILE%\.config\opencode\plugins\isle\index.ts` (або `%APPDATA%\opencode\plugins\isle`).
Він надсилає `working` / `done` / `error` / `attention`, а панель агентів показує
стан хука, кількість запитів і останню подію. Вихідний код — `integrations/opencode/isle`.

## Приватність

- Усе зберігається локально: `%APPDATA%\Isle\settings.json`, `isle.db`.
- Немає телеметрії, реклами, підписок і обов'язкових акаунтів.
- У мережу йдуть лише явно увімкнені запити: погода Open-Meteo, тексти LRCLIB,
  фолбек-обкладинки iTunes/Deezer (лише назва/виконавець), переклад MyMemory (лише текст),
  ШІ-endpoint (за замовчуванням локальний Ollama). API-ключ шифрується Windows DPAPI у
  `settings.json` і не пишеться в логи.
- Історія буфера (текст і зображення) та нотатки не синхронізуються нікуди. Паролі, приватні
  ключі, JWT і ключі відомих сервісів не потрапляють в історію, якщо увімкнено фільтр.
- Зображення буфера зберігаються локально в `%APPDATA%\Isle\clipboard-images`.

## Відомі обмеження

- Відеозапис екрана, плагіни сторонніх розробників і автооновлення не входять у 1.6.
- FPS у грі потребує PresentMon/ETW і прав адміністратора; без них віджет показує частоту екрана.
- Температура CPU/GPU залежить від прошивки та драйвера: на частині ПК потрібні права
  адміністратора або запущений LibreHardwareMonitor. Якщо датчика немає, віджет показує «—».
- Перекладач використовує безкоштовний MyMemory і потребує інтернету; є добовий ліміт.
- Код-підпис відсутній: SmartScreen може попереджати про невідомого видавця.
- Автооновлення немає; нова версія встановлюється поверх інсталятором.
- Android-застосунок потребує збірки в Android Studio (готового APK у репозиторії немає).
- iPhone не дозволяє пересилати системні сповіщення стороннім застосункам; на iPhone доступні
  веб-версія (буфер, файли, пейринг), а не пересилання сповіщень.
- RemoteInput (відповіді на сповіщення з ПК) не реалізовано — обмеження Android.
- OCR залежить від мовних пакетів Windows; для української/російської встанови
  відповідний мовний пакет у Windows.
