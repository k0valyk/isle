# Isle — дизайн-система

Документ описує напрям, токени й правила, за якими зроблено інтерфейс 1.6.1.
Будь-яка нова вкладка, віджет або налаштування мають їм відповідати.

## Напрям

- **Продукт.** Швидкий оглядовий центр керування, що живе біля верхнього краю екрана.
- **Характер.** Спокійний, точний, трохи теплий.
- **Світ.** Нічний приладовий панно: матовий графіт із ледь теплим відтінком, як анодований алюміній. Не синє скло, не неон.
- **Акценти.** Обкладинка треку й циферблат таймера — єдині насичені моменти.
- **Підпис.** Одна волосяна лінія світла по верхньому краю капсули + одна жива точка статусу.

## Токени

| Токен | Призначення |
|---|---|
| `--bg`, `--bg-elevated` | Фон і піднятий фон (сайдбар, прев'ю) |
| `--fg`, `--muted` | Основний і другорядний текст (третій рівень — `color-mix`) |
| `--surface`, `--surface-strong`, `--surface-raised` | Три рівні поверхонь |
| `--border`, `--border-strong` | Волосяні рамки 7–8% і 14–18% |
| `--accent` | Один акцент: вибір, головна дія, один показник |
| `--radius-control` 9 / `--radius-card` 14 / `--radius-panel` 18 | Вкладені радіуси |
| `--text-xs` 10.5 / `--text-sm` 12 / `--text-md` 13 / `--text-lg` 15 / `--text-xl` 18 | Шкала |
| `--motion-duration`, `--motion-ease`, `--motion-fast` | Профіль анімацій (4 пресети) |
| `--btn-primary-bg` / `--btn-primary-fg` | Головна кнопка: світла на темному, темна на світлому |
| `--focus-ring` | Помітне кільце фокуса для клавіатури |

## Правила

1. **Відступи кратні 4.** Рядок налаштувань — 44 px, картка — 14 px радіус і 16 px падінг, сторінка — 24–32 px.
2. **Один акцент.** Акцент не фарбує поверхні, рамки, ховери чи іконки за замовчуванням.
3. **Глибина — це рівні поверхонь і волосяні рамки**, а не тіні. Кольорові тіні, градієнтні заливки, свічення й неонові рамки заборонені.
4. **Текст.** Тільки sentence case. Ваги 400/500, 600 — рідко. Жодних UPPERCASE-лейблів із трекінгом, курсиву, градієнтного тексту.
5. **Цифри** — `tabular-nums`, один формат на екран.
6. **Іконки** — один набір (власний `Icon.svelte`), один розмір у межах шару, колір тексту, без емодзі.
7. **Ховер** — зміна фону/рамки, **натиск** — `scale(0.98)`, без стрибків макета.
8. **Анімація** — тільки `transform`/`opacity`; одна крива на профіль; поважати `reduced_motion` і `prefers-reduced-transparency`.
9. **Контраст.** Основний текст ≥ 4.5:1 на своїй поверхні; рамки й контроли ≥ 3:1.
10. **Вкладені радіуси** додаються: внутрішній = зовнішній − падінг, мінімум 4.

## Де що застосовано

- `src/app.css` — токени, базові контроли, фокус, reduced-motion.
- `src/lib/store.svelte.ts` — палітри тем (classic/night/light + декоративні), профілі руху.
- `src/IslandApp.svelte` — капсула, хром, таби, банери, згорнутий стан.
- `src/lib/widgets/WidgetCard.svelte` + `src/lib/modules/home/Home.svelte` — сітка віджетів.
- `src/SettingsApp.svelte` — сайдбар, рядки, прев'ю.
- `src/lib/modules/player/Player.svelte`, `timer/Timer.svelte` — акцентні моменти.

## Чого не робити

- Не додавати нові кольори «для краси»: новий відтінок = нове значення (помилка, успіх, попередження).
- Не повертати `text-transform: uppercase` для дрібних підписів.
- Не ставити тіні на картки у темній темі.
- Не анімувати `width`/`height`/`top`/`left` у контенті (це робить лише морфінг капсули, синхронізований з нативним регіоном).
