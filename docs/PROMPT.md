# docs/PROMPT.md

Це посилання на повний технічний промт проєкту Isle (розділи 0–18), який даний користувачем у чаті. Короткий огляд:

- Етап 1: каркас (вікно острова, анімація, годинник, погода, трей, i18n).
- Етап 2: музика (SMTC, тексти, FFT, персонажі).
- Етап 3: інструменти екрана (буфер, Alt+Space, скріншоти, OCR, QR, запис).
- Етап 4: продуктивність (текст, нотатки, таймер, нагадування, календар).
- Етап 5: мережа й ШІ (чат, погода, Wi-Fi/VPN, завантаження).
- Етап 6: телефон (Android, пейринг, сповіщення, файли).
- Етап 7: агенти й розширення (Claude Code/Codex/OpenCode хуки, термінал, плагіни).
- Етап 8: полірування (перформанс, баги, доступність, інсталятор, оновлення).

Жорсткі умови: розділ 0 (безкоштовно, приватність, бюджети).
Правила коду: розділ 14. Пріоритет при конфліктах: розділ 17 > пізніший номер > раніший.

Стан 1.6: усі вісім етапів реалізовано в обсязі, описаному в README. Свідомо поза
межами 1.6: відеозапис екрана, плагіни, автооновлення (див. BUILD.md).
